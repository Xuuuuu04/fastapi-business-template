## 每包文档

每包维护：

| 文件 | 用途 |
|---|---|
| `needs.md` | 使用者、问题、功能与明确不做项 |
| `rules.md` | 规则编号、计算、异常、确认样例及待确认问题 |
| `changes.md` | 已确认变化、生效时间、旧数据与接口影响 |
| `flows.md` | 从代码生成的接口、步骤、字段来源与数据表 |

规则预期由产品确认，测试使用对应样例；未知业务含义不能自行补齐。手写业务文档每份不超过200行，变长按主题拆分，保留业务条件。生成文档不手工修改。

生成结构： [接口](api/index.md)、[模块关系](modules.md)、[开发计划](development.md)、[规则进度](progress.md)。它们说明声明和计划，实际检查与运行情况由项目阅读 Skill 查询。未完任务使用项目已有任务记录；需要产品任务清单时再创建，不预置模板历史。
