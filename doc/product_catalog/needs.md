# 商品目录：需求

> 这是模板自带的示例业务，用来演示写法。用模板开发真实产品时，删除或替换为真实需求。

## 谁使用

- 运营人员：维护商品的编码、名称、单价和在售状态。
- 订单报价模块：查询可以报价的商品单价。

## 要解决什么问题

报价时需要一个可信的商品单价来源。商品编码由人手工录入，常见大小写不一、前后带空格的情况，需要统一。

## 功能

| 功能 | 说明 | 对应操作 |
| --- | --- | --- |
| 查询商品 | 分页查看商品，可只看在售或停售 | product_catalog.list_products |
| 读取商品 | 按编号查看一个商品 | product_catalog.get_product |
| 新建商品 | 编码整理后不能与已有商品重复 | product_catalog.create_product |
| 修改商品 | 修改编码、名称、单价、在售状态 | product_catalog.update_product |
| 删除商品 | 删除一个商品 | product_catalog.delete_product |
| 查询可报价的单价 | 只给订单报价等内部模块使用 | product_catalog.get_prices |

## 明确不做

- 不管理库存、采购和价格审批。
- 不保存价格的历史版本；修改单价只影响之后的新报价，已保存的报价不变。
