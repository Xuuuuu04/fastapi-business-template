# 文件管理：规则

以下为通用模板的默认规则；具体项目启用前需确认允许的文件类型和保留时间。

### R-01 上传

上传文件名只保留最后一段，扩展名必须在 `APP_UPLOAD_SUFFIXES` 中，大小不得超过 `APP_UPLOAD_MAX_BYTES`。临时文件保存 SHA-256、大小和内容类型；保存时生成不可猜测的文件编号，并把存储键加上模块前缀。

| 输入 | 结果 |
| --- | --- |
| 北区用户上传 `report.pdf`，后续保存成功 | 返回文件编号、名称、大小和 SHA-256 |
| 上传不在允许列表的扩展名 | 拒绝上传，不产生正式文件记录 |

### R-02 组织隔离

文件记录属于上传者的组织。查询、下载和删除都必须使用与调用者组织相等的条件；没有组织编号或访问别的组织文件时拒绝。系统管理员的组织范围 `*` 可以跨组织访问。

| 输入 | 结果 |
| --- | --- |
| 南区用户下载北区文件编号 | 返回未找到，文件内容不输出 |

### R-03 删除和清理

删除先在数据库标记，下载立即不可用。后台清理任务删除正式存储中的已标记文件，再删除记录；临时区超过一小时的文件由后台任务清理。对象存储和数据库不能共同提交，后台任务还会清理超过一小时仍没有文件记录的正式对象，单次最多一百个。保存结果不明时可用文件编号查询记录；一小时内不自动清理，避免误删正在保存的文件。
