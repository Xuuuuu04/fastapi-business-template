# 用户权限：规则

以下为通用模板的默认规则。R-02 的授权限制于 2026-09-24 经用户确认；R-03、R-05 至 R-07 按用户要求采用行业通行做法（OAuth 2.0 安全最佳实践 RFC 9700、OWASP 令牌建议）。具体项目启用前仍需检查组织和权限划分。

### R-01 组织

组织代码由小写字母、数字和短横线组成，长 3 至 32 字符，全系统唯一。只有拥有 `user_access.system` 权限且组织范围为 `*` 的调用者能创建组织。名称去掉首尾空白后保存。

| 输入 | 结果 |
| --- | --- |
| 代码 `north`、名称 ` 北区 ` | 创建代码为 `north`、名称为 `北区` 的组织 |
| 再次创建 `north` | 返回代码冲突 |

### R-02 角色与用户

角色只属于一个组织，名称在组织内唯一；角色保存权限名列表。授予角色的权限必须是授予者自己拥有的权限；`user_access.system`、`system.diagnostics`、`system.jobs`、`system.*` 能看到或操作全部组织的数据，只能配给组织范围为 `*` 的服务密钥，不能放进组织角色。`system.audit` 只返回本组织的审计记录，可以放进组织角色。用户在同一组织内以用户名唯一识别，密码用 scrypt 保存。组织管理员只能管理自己的组织；跨组织或没有组织编号的请求被拒绝。停用用户后不能再登录，他的全部刷新令牌立即作废，已经签发的访问令牌最多 15 分钟后失效（R-05）。调整角色后，新权限在用户下一次刷新时生效，最长 15 分钟。

| 输入 | 结果 |
| --- | --- |
| 北区创建角色 `viewer`，权限 `product_catalog.read` | 北区用户可被分配这个角色 |
| 北区管理员请求南区用户列表 | 拒绝访问 |
| 只有 `user_access.manage` 的北区管理员创建含 `product_catalog.write` 的角色 | 拒绝访问：超出自己的权限 |
| 任何调用者创建含 `system.diagnostics` 的组织角色 | 拒绝访问：跨组织的系统权限 |

### R-03 登录和令牌

登录同时核对组织代码、用户名、密码和启用状态。失败统一返回“账号或密码不正确”，不说明哪一项存在；同一组织、用户名和来源地址连续失败 5 次后，15 分钟内拒绝登录。成功后返回访问令牌和刷新令牌（R-05）。访问令牌为 HS256 签名，有效 15 分钟，包含用户编号、组织编号和签发时的权限；校验签发方、接收方和过期时间，不查数据库。更换签名密钥时，旧密钥可以在过渡期内继续用于校验。

| 输入 | 结果 |
| --- | --- |
| 正确的组织代码、用户名和密码 | 返回 `access_token`（15 分钟）、`refresh_token`（7 天）和各自剩余秒数 |
| 错误密码或停用用户 | 返回相同的登录失败错误 |

### R-04 管理权限

创建、查询和调整用户或角色需要 `user_access.manage`；创建组织需要 `user_access.system`。组织范围 `*` 的系统管理员可查看全部组织，普通管理员仅能查看自己的组织。接口返回用户信息时不返回密码摘要。

### R-05 刷新令牌与登录会话

一次登录形成一个登录会话。刷新令牌是 256 位随机值，数据库只保存 SHA-256 摘要。刷新令牌 7 天不用就失效；一次登录最长保持 30 天，之后必须重新输入密码。每次刷新都换一个新的刷新令牌，旧的随即作废，同时按用户当前的启用状态和角色权限签发新的访问令牌。已经用过的刷新令牌再次被提交，说明它可能被盗用，这次登录会话的全部刷新令牌立即作废，用户需要重新登录。退出登录作废这次登录会话；令牌无效时同样返回成功，不暴露令牌是否存在。

| 情况 | 结果 |
| --- | --- |
| 用 7 天内的刷新令牌刷新 | 返回新的访问令牌和新的刷新令牌，旧刷新令牌作废 |
| 旧刷新令牌已经换过新令牌，又被提交 | 拒绝；刚换出的新刷新令牌也一起作废 |
| 用户已停用，或退出登录后再刷新 | 拒绝，提示重新登录 |
| 同一个刷新令牌被两个页面几乎同时提交 | 按重复使用处理，两个页面都要重新登录；前端应当只让一处负责刷新 |

### R-06 修改自己的密码

已登录用户提交原密码和新密码（8 至 256 个字符）。原密码不正确时拒绝，不做任何修改。修改成功后，这个用户的全部登录会话作废，所有设备都需要用新密码重新登录。服务密钥不是用户，不能使用这个操作。

| 输入 | 结果 |
| --- | --- |
| 原密码错误 | 返回“原密码不正确”，密码不变 |
| 原密码正确 | 密码更新；旧刷新令牌失效，旧密码不能再登录 |

### R-07 清理刷新令牌记录

系统任务每天 04:00 删除过期或作废超过一天的刷新令牌记录，保留一天供排查。
