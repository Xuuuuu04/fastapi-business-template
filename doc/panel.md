# 离线开发面板

在 `server` 目录运行 `uv run dev panel`，打开生成的 `out/panel/index.html`。页面包含全部脚本、布局库与样式，不需要服务或网络。`dev finish` 收工检查后自动刷新；源码修改后，已经打开的 HTML 需要重新生成并刷新浏览器。

项目图保留计划包和未列入计划的真实包，实线来自公开调用，虚线来自计划，紫色线表示已登记的只读例外，蓝色线表示工具引用，红色线显示现有静态检查发现的违规跨包导入，并附源码位置。真实公开声明无法加载时，先按命令错误修正声明；面板不能凭空还原不存在的契约。

点击节点查看公开操作、模拟身份、步骤位置、规则确认、最近三轮检查范围、各库计数与时间。包名或用途搜索、业务线筛选、键盘 Enter 和空格均可操作。长链默认保持节点原始大小，在图内横向滚动；适应画布可缩小总览。

| 状态 | 证据含义 |
| --- | --- |
| 计划 | 项目计划中存在，尚未登记代码 |
| 骨架 | 仍有显式模拟步骤 |
| 开发中 | 有未完成或需要更新的任务 |
| 缺少证据 | 没有正式包检查，工具包尚无独立整链稳定证据 |
| 证据过期 | 最近留存检查不属于当前包源码 |
| 待验证稳定性 | 有当前检查，连续三次整链同轮双库成功尚未齐全 |
| 当前检查失败 | 最近当前源码正式检查失败，快速成功不能覆盖它 |
| 稳定通过 | 当前包和实际调用方连续三次同轮双库通过，所有相关操作实际执行，样例没有失败、跳过或模拟 |

同一源码出现成功和失败时，闪电标记表示检查不稳定，不能显示稳定绿色。绿色只说明检查通过，不证明业务验收。高风险待确认规则另用紫色角标表示，规则确认和交付仍需单独判断。

橙色边框提示评估拆包：包源码超过 1000 行、超过 20 个步骤、超过 8 个依赖，或存在跨包同结构函数。这些是整理建议，不降低既有文件、函数和依赖质量要求；同结构提示不证明业务语义相同。

备注可写在本机 `.agents/records/notes/包名.md`，只展示前 4000 字，不参加指纹和颜色计算。页面不会执行备注中的 HTML 或脚本。确认资料、契约请求和收工审查单分别展示，测试输入、SQL、返回值、回执和本机原话档案不会复制进页面。

分支图只读取本地 Git，不切换分支、不拉取远程、不改变其他工作树。每个工作树的检查记录独立展示，明确表示历史记录，未载入其当前契约时不声称当前通过。大于 4 MiB 的旧记录需在其自身工作树通过状态命令转换；面板不会替它创建缓存。分支同包变更只表示可能冲突，实际整合仍需合并检查。

完整检查耗时曲线、通过率、最近完整轮十项最慢测试和规则分布来自留存证据。测试累计时间包括该包相关测试各阶段之和，整轮耗时是墙上时间；并行情况下两者不相等。删除证据会失去复核依据；证据损坏时命令失败，并替换旧页面为错误说明，防止继续误用旧的绿色结果。
