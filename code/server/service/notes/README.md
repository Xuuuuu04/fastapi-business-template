# 笔记示例

此功能用于体验单体后端的完整调用过程。公开读取，写入需要密钥；没有用户归属。

| 文件 | 作用 |
| --- | --- |
| types.py | 业务数据和错误 |
| needs.py | 所需存储操作 |
| service.py | 规则与事务 |
| store/sqlite.py | SQL 查询和保存 |

标题去掉首尾空白后唯一，区分大小写。正文允许为空。PUT 完整替换标题与正文；DELETE 缺失记录返回 404。列表按编号倒序。

此示例可以整体替换为真实业务。使用 dataclass 表达业务数据，接口使用 Pydantic，二者在路由处转换。
