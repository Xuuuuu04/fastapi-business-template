# 后台任务

保留完整设计，有耗时、定时或需要恢复的工作时启用。当前没有任务执行代码，也未选择队列产品。

- 提交：登记任务编号、调用者、输入和重复提交规则。
- 执行：独立任务进程领取任务，调用组装好的业务服务。
- 状态：记录等待、执行、成功、失败、取消和结果未知等适用状态，以及进度和错误。
- 恢复：按任务性质设计重试、超时、取消和服务重启后的恢复。
- 定时：按明确时区和去重规则触发，不让多个 Web 进程重复安排同一任务。

shared/jobs 提供调度与状态机制，业务决定计算、允许重试的条件和副作用规则。需要恢复的任务状态不能只放内存。涉及外部写入时，超时不代表未执行，不默认自动重发。

任务入口由 app/setup 组装，app/api 只负责提交、查询和请求取消。FastAPI 响应后的轻量后台操作与可恢复任务分开说明。

验证应覆盖失败、重启、重复领取、取消及实际受影响的并发情况。
