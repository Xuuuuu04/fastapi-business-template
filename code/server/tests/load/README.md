# 压力与性能检查

启动隔离的本机实例后执行：

```bash
uv run python tests/load/run.py --port 8000 --count 100 --workers 4
```

当前脚本是轻量只读负载检查，输出失败率、吞吐量和 P50/P95 耗时。任何失败返回非零退出码。默认测试不运行它，避免每次开发都产生负载。

要评估监控开销，在相同数据库、请求数和并发下分别使用 APP_MONITOR=true / false，预热后多次测量。当前未设性能验收阈值，也未验证长时间运行、复杂查询、并发写入和多进程容量；这些场景随真实业务增加，不能用本机短测试替代生产容量评估。
