# 模板设计入口

[通用后端模板设计](通用后端模板设计.md) 是当前唯一的设计总稿，保存已确认决定、设计建议、理由和待讨论事项。当前为第三轮实践复核稿：只读学习实际项目后，补充数据消费、版本冻结、批量结果及外部执行恢复；不包含参考项目的业务实现，尚未批准开始开发。

本轮优先阅读第 2.1 节发现的问题及第 17 节建议实施的范围。确认范围后再授权开发，设计修订不代表实现已通过验收。

## 阅读顺序

| 想了解什么 | 阅读位置 |
| --- | --- |
| 已经决定什么、哪些判断需要修正 | 第 1、2 节 |
| 目录、分层、模块、计算图和数据 | 第 3 至 6 节 |
| 模块、数据、任务如何一次声明并验证接线 | 第 4.3、14 节 |
| 多个模块共同写入，谁提交和回滚 | 第 5.3 节 |
| 数据何时可用，如何解释缺值、来源与历史结果 | 第 6.2 至 6.5 节 |
| 中文摘要、实时观察及字段追踪 | 第 7、8 节 |
| 历史存在哪里，哪个结果可信 | 第 8.4、9.4 节 |
| 短任务能否使用队列、有什么成本 | 第 9 节 |
| 外部已受理、本地重启及计划未触发如何处理 | 第 9.5、9.6 节 |
| API、安全、部署、版本与质量检查 | 第 10 至 14 节 |
| 迁移、失败场景验收和实际进度 | 第 15、16 节 |
| 推荐选型、实施顺序及上线前条件 | 第 17 节 |

后续更新对应章节，不另写内容重复的架构总稿。修改设计不代表已经实现；已确认决定、候选方案和代码现状必须分别记录。

本目录服务于“模板本身”的设计。未来具体业务产品的需求、计算规则和确认样例，按总稿建议放入产品自己的业务文档，不复制本次会话记录。
