## 规则

### R-01 标题整理

保存前去掉首尾空白；去掉后不能为空，最长 80 个字。

| 输入 | 结果 |
| --- | --- |
| "  月度计划 " | "月度计划" |
| 全空格 | 拒绝保存 |
| 80 个字，前后另有空格 | 去掉空格后保存 80 个字 |
| 81 个字 | 拒绝保存 |
