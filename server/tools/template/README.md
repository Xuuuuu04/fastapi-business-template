# template：新项目与框架更新

`tools.start_project` 生成不含模板讨论、验收记录或本机资料的新项目；
`tools.update_framework` 比较旧模板、当前项目和新模板，只接收框架目录中的变化。

- `files.py`：明确可更新范围、安全路径与模板来源摘要。
- `merge.py`：逐文件比较与更新，任何冲突都会阻止全部写入。
- `initialization.py`：建立新项目的原生文档和空业务计划。
- [UPGRADING.md](UPGRADING.md)：老项目使用步骤、依赖与数据库变更的人工处理。

业务代码、注册清单、业务文档、迁移历史、配置、项目计划、依赖版本与锁文件归项目所有。
工具不执行数据库操作、不安装依赖、不推送代码。更新后仍需审查差异、生成框架摘要并完整检查。
