# model_calls：大模型调用入口

步骤通过 `model` 参数调用大模型，只能使用在 `@step(prompts=[...])` 中声明过的提示词。

## 文件

| 文件 | 内容 |
| --- | --- |
| [prompt.py](prompt.py) | `prompt()`：提示词文件带版本；变量写作 `{name}`，缺少或多出都报错 |
| [service.py](service.py) | 并发上限、暂时故障重试、记录模型名、提示词版本、token 用量和耗时 |
| [gate.py](gate.py) | 步骤拿到的 `model`：`ask()` 返回文本，`ask_data()` 返回校验后的结构化结果 |
| [providers.py](providers.py) | 服务商实现：OpenAI 兼容接口（覆盖多数国内外服务商）和测试用的模拟实现 |

## 规则与原因

- 提示词版本号的作用与业务规则版本相同，写进运行记录；改了提示词内容就改版本号。
- 原始提示词和回复默认不保存，只在 `APP_MODEL_KEEP_TEXT=true` 时保存截断的文本，避免业务数据进入记录。
- 重试由入口统一处理，模块不要自己再包一层重试，否则请求量会成倍增加。
- 本地和测试没有配置模型时使用模拟回复；生产环境声明了提示词却没有配置模型，启动失败。
- 要接入 Claude，请新写一个基于官方 anthropic SDK 的实现，不要通过兼容接口转接。
