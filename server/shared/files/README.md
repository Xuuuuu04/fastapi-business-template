# 文件存储底层

`storage.py` 提供本地目录和 S3 兼容存储；`uploads.py` 接收临时上传并限制大小、扩展名；`gate.py` 给模块的存储实现提供带模块前缀的文件操作。文件记录、权限和下载接口由产品业务模块管理。正式存储键不得包含 `..`。存储实现支持按模块前缀逐项列出对象，供后台任务清理没有文件记录的对象。

`ModuleFiles.read_upload(temp_id, max_bytes)`有界读取临时原件，不移动文件；
`discard_upload`清理业务已确认的重复上传。`save_bytes`保存模块自己生成的内容，
`exists`检查正式文件；存储键仍限定在模块前缀内。文件增长后读取上限仍有效。
