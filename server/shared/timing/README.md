# 时间与预算

Clock.now是业务UTC时间，用于持久排队、有效期、冷却与租期；Clock.monotonic用于进程内消耗和执行截止。重启时不能恢复原进程的单调绝对时间，必须按持久业务截止重新计算剩余预算。

正式组装默认RealClock；测试显式传入FakeClock，通过advance推进。set_wall模拟系统校时，不改变当前单调预算。等待和期限都通过同一个时钟，不让测试真的等待冷却或一天。

排队预算、单次执行预算、供应商调用预算、业务有效期和整链截止分别声明。上层预算不足时报告具体声明位置，不把几类时间混成一个timeout。外部取消只能停止等待，已经发送的效果仍按持久意图查证。
