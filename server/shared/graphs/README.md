# graphs：四种图与诊断报告

四种图都从同一份声明或运行记录生成，不另外手画：

| 图 | 来源 | 回答的问题 |
| --- | --- | --- |
| 模块关系图 [static.py](static.py) | 步骤的 `uses` | 哪个模块经由哪些操作调用哪个模块 |
| 计算流程图 [static.py](static.py) | 流程的步骤顺序 | 一个操作按什么顺序执行哪些步骤、有哪些条件 |
| 字段来源 [lineage.py](lineage.py) | 步骤的 `reads`、`writes` 和规则编号 | 某个字段由哪一步、按哪条规则、用哪些字段算出 |
| 实际执行图 [observed.py](observed.py) | 运行记录 | 这一次走了哪些步骤、哪里失败、每步用时多少 |

[observed.py](observed.py) 还生成中文诊断报告：先给摘要，再列每一步的规则、写入、说明和源码位置。排查问题时先看报告，再读对应规则和源码，不必从头读代码。

字段来源精确到步骤；具体公式看对应步骤的源码和业务规则文档。图中的文字一律转义（[mermaid.py](mermaid.py)），输入内容不会被当成图语言执行。
