# data：字段说明与数据基类

## 负责

- `meaning()`：给每个字段写中文含义。单位、规则编号、空值含义、是否记录取值、是否敏感，都写在字段上。接口文档、字段表、运行记录、字段来源图都读这里，不另外维护一份说明。
- `Data`：接口和模块之间传递的数据，创建后不能修改，不接受多余字段。
- `WorkData`：一次流程会用到的和会产生的字段。它只描述字段，不创建实例；执行器按步骤的声明来读写。

## 规则与原因

| 规则 | 原因 |
| --- | --- |
| 每个字段都要写 `meaning()` | 不写含义，后来的人和 AI 只能猜字段用途 |
| 可空字段必须写 `empty=` | 区分“没有数据”“尚未定价”“不适用”，避免都变成 None 或 0 |
| 金额用 `Decimal`，不用浮点数 | 执行器写入时严格校验类型，浮点数会被拒绝 |
| `secret=True` 的字段不记录任何内容 | 令牌、证件号等不能进入运行记录和日志 |
| `log_value=True` 才记录取值 | 默认只记录数量、长度，避免记录业务数据原文 |

不要用万能字典代替明确的数据类型，也不要让所有数据都继承一个带 id 和创建时间的实体基类。
