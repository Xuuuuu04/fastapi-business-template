# access：调用者身份与权限

- [caller.py](caller.py)：`Caller`（编号、种类、名称、权限）。权限写作“模块名.动作”，`模块名.*` 表示该模块全部权限，`*` 表示全部权限。
- [keys.py](keys.py)：服务密钥。配置里只保存 SHA-256 摘要和权限，用固定时间比较；新密钥用 `tools.make_key` 生成。

## 规则与原因

- 身份只来自已验证的凭据，请求正文里自报的身份一律不用。
- 匿名调用受保护的操作返回 401；有身份但缺权限返回 403。
- 本地开发身份（`APP_DEV_CALLER`）只在 `local` 环境生效，生产环境开启会拒绝启动。
- 任务执行时，服务密钥按当前配置重新取得权限；密钥被删除后，排队中的任务不再执行。
- 接入用户登录（例如 JWT）时，在 `app/api/identity.py` 增加识别方式，业务模块不需要改。
