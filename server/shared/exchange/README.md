# exchange：导入导出的表格文件

[sheets.py](sheets.py) 读写 CSV（UTF-8）和 Excel（.xlsx），只做格式转换，由接口层调用：

- `read_sheet(内容, 文件名, 表头对应字段, {必需的字段: 表头名称})`：返回 `(行号, {字段: 文字})`；行号就是文件里的行号，便于逐行报告错误。表头可以写中文或字段名。
- `write_sheet(行, 字段对应表头, "csv" 或 "xlsx")`：生成文件内容；`MEDIA` 是对应的内容类型。

| 规则 | 原因 |
| --- | --- |
| 读出的值都是文字，由业务步骤按规则检查和转换 | 格式转换与业务规则分开，出错能按行号和规则编号说明 |
| 一次最多 5000 行，空文件、缺少必需列、不是 UTF-8 的 CSV 直接报错 | 大文件改用后台任务分批处理；格式问题不能静默跳过 |
| 空行跳过 | Excel 常在末尾留空行 |

接口层负责读取文件并转换成行，业务流程按明确的规则检查；无效的行怎么处理由业务规则决定。可重复运行的读写样例见 `tests/framework/test_sheets.py`。
